# Pawfect

A React + Vite pet matching app built with JavaScript, Tailwind CSS, and source-managed shadcn/ui primitives.

## Run locally

```bash
npm install
npm run dev
```

The app loads 15 random pets from `https://pet.btholt.workers.dev/pets/random/15` when it starts. Use Pass or Like, the Left and Right arrow keys, and the lower-left theme button to move through the experience.

## Checks

```bash
npm run lint
npm run build
```
